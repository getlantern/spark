# iOS Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. NOTE: Phase 0 (Xcode/packaging) and every on-device step are **interactive** — driven by the controller + a human with the iPhone, not a headless subagent. The Rust/config/UI tasks (Phase 1 + parts of 3) are subagent-friendly.

**Goal:** Ship iOS as a new platform target of the existing `tauri-plugin-spark-vpn`, reusing the macOS `AppleControl`/`ne_spike` control path, with the Network Extension packaged as an app-extension inside the Tauri iOS app.

**Architecture:** De-risk → reuse → wire → validate. Prove NE-app-extension packaging/co-signing inside a Tauri iOS `.ipa` on a physical iPhone FIRST (Phase 0, hard gate). Then cfg-gate the existing Apple control for iOS (no new plugin, no Swift shim), swap the spike stub for the real shared `PacketTunnelProvider.swift`, wire all features, and validate on device under the 50 MiB NE memory cap.

**Tech Stack:** Tauri v2 iOS (WKWebView + `gen/apple` Xcode project), Swift NetworkExtension (`NEPacketTunnelProvider`), Rust `objc2-network-extension` (`NETunnelProviderManager`), the `spark-apple` C-ABI + `SparkCore.xcframework` (iOS slices already built), `spark-core`. Spec: `docs/superpowers/specs/2026-07-09-ios-support-design.md`.

- [ ] **Step 4: Create the spike stub provider (iOS-only, temporary)**

Create `platforms/apple/Sources/SparkNE/SpikeTunnelProvider.swift` (used ONLY for the Phase-0 packaging spike; Task 2.1 replaces it with the real shared provider):
```swift
import NetworkExtension

/// Minimal packet-tunnel provider used only to prove the NE app-extension packages, co-signs, and
/// launches inside the Tauri iOS app. It applies a trivial tunnel network settings and reports
/// connected — it does NOT run the core. Phase 2 swaps the target's principal class to the real
/// shared PacketTunnelProvider.
final class SpikeTunnelProvider: NEPacketTunnelProvider {
    override func startTunnel(options: [String: NSObject]?, completionHandler: @escaping (Error?) -> Void) {
        let settings = NEPacketTunnelNetworkSettings(tunnelRemoteAddress: "127.0.0.1")
        let ipv4 = NEIPv4Settings(addresses: ["10.0.0.2"], subnetMasks: ["255.255.255.0"])
        ipv4.includedRoutes = [NEIPv4Route.default()]
        settings.ipv4Settings = ipv4
        setTunnelNetworkSettings(settings) { error in completionHandler(error) }
    }

    override func stopTunnel(with reason: NEProviderStopReason, completionHandler: @escaping () -> Void) {
        completionHandler()
    }
}
```
