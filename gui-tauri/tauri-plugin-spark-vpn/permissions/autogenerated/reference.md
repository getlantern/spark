## Default Permission

Allows all spark-vpn tunnel-control commands.

#### This default permission set includes the following:

- `allow-connect`
- `allow-disconnect`
- `allow-status`
- `allow-servers`
- `allow-select-server`
- `allow-get-split-tunnel`
- `allow-set-split-tunnel`
- `allow-get-routing-mode`
- `allow-set-routing-mode`
- `allow-get-ad-block-enabled`
- `allow-set-ad-block-enabled`
- `allow-list-installed-apps`
- `allow-get-excluded-apps`
- `allow-set-excluded-apps`
- `allow-unbounded-start`
- `allow-unbounded-stop`
- `allow-unbounded-status`
- `allow-unbounded-get-settings`
- `allow-unbounded-set-settings`
